Website Admin Guide 🌸

This simple admin page explains how to update the proposal website files.

Change the photos

  1. Open assets/images/.
  2. Replace the sample files with your own photos, keeping the exact names a.jpg through g.jpg.
  3. Keep the same JPG format and spelling.

Change the music

  1. Open assets/music/.
  2. Put your audio file there and name it music.mp3.

This is a static website. There is no online login, database, or remote admin panel in this lightweight version. Edit the files in the repository to update the site.
