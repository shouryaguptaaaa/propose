Admin Guide 🌷

Is website ko customize karne ki simple guide.

Zaroori baat: ye website static hai. Isme koi login, database ya backend nahi hai. Is page se kuch save ya upload nahi hota. Content badalne ke liye files ko GitHub mein edit ya upload karna padta hai. Is page ka kaam sirf guide dena aur files check karna hai.

1. File check

Ye check karta hai ki saari 7 photos aur music file sahi jagah par mil rahi hain ya nahi.

    2. Saari 7 photos badalna

    1. Apni 7 photos ke naam bilkul aise rakho: a.jpg, b.jpg, c.jpg, d.jpg, e.jpg, f.jpg, g.jpg
    2. GitHub repo propose mein assets/images/ folder kholo.
    3. Add file → Upload files dabao aur photos select karo.
    4. Same naam ki file pehle se hai to wo replace ho jaati hai. Commit changes dabao.
    5. 1 to 2 minute baad site refresh karo. Purani photo dikhe to cache clear karo ya page hard refresh karo.

    Tip: Mobile par site tez chale, iske liye har photo 1 MB se chhoti rakho. Extension sirf .jpg hona chahiye, .jpeg ya .png nahi.

    3. Music upload karna

    1. Apni song file ka naam music.mp3 rakho.
    2. GitHub mein assets/music/ folder kholo.
    3. Add file → Upload files se music.mp3 upload karo aur commit karo.

    Music apne aap nahi bajta. Visitor ko neeche wala music button dabana padta hai, ye browsers ka rule hai. File 5 MB ke aaspaas rakho taaki jaldi load ho.

    4. Proposal ka message edit karna

    Ye teen jagah index.html mein hain. GitHub mein file kholo, pencil icon dabao, text badlo aur commit karo.

    Main heading aur intro 
    <h1>Will you make my day <span class="script">special?</span></h1>
<p class="intro">I have a question to ask… and I hope it makes you smile.</p>
    Proposal card ka sawaal aur message 
    <h2 id="askTitle" class="card-title">Will you say yes?</h2>
<p class="subtext">Yahan apna emotional message likho.</p>
    YES dabane ke baad wala thank-you message 
    <h2 id="successTitle" class="success-title">Thank you 💖</h2>
<p class="success-text">Yahan special message likho.</p>

    5. 100 reasons customize karna

    Saare reasons script.js mein const reasons = [ ... ]; ke andar hain. Rules:

    • Exactly 100 reasons hone chahiye, na kam na zyada.
    • Har reason alag hona chahiye. Repeat nahi hona chahiye.
    • Har line quotes mein ho aur line ke end mein comma ho.

    Neeche apne reasons ek line mein ek likho. Tool count karega, duplicates dikhayega aur paste karne layak code bana dega.

    Count: 0 / 100 

    // Yahan generated code aayega

    Phir script.js mein purana const reasons = [ ... ]; poora hatao aur ye naya block paste karo.

    6. Baaki website content update karna

    • Rang aur design: style.css ke top par :root mein colors hain.
    • Page ka title: index.html ka <title> tag.
    • Footer text: index.html mein class="footer".
    • Photo caption ya alt text: index.html mein har <img alt="...">.

    Har change ke baad GitHub mein Commit changes dabao. GitHub Pages 1 se 2 minute mein site update kar deta hai.

    7. Deploy ya update ka quick flow

    1. Repo: shouryaguptaaaa/propose
    2. Settings → Pages → Branch main → folder / (root) → Save.
    3. Site link: https://shouryaguptaaaa.github.io/propose/
    4. Codespaces mein ho to terminal mein ye chalao:
    git add .
git commit -m "Update website"
git push
